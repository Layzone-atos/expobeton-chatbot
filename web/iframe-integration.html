🏗️ Intégration du Chatbot ExpoBeton RDC via iframe

Copiez-collez le code ci-dessous dans votre site web pour afficher le chatbot flottant.

📋 Méthode 1 — Intégration simple (recommandée)

Collez ce code juste avant la balise </body> de votre page :

<!-- ExpoBeton RDC Chatbot (bouton à GAUCHE) -->
<iframe
    id="expobeton-chatbot"
    src="https://web-production-9f398e.up.railway.app/web/chatbot-embed-left.html"
    title="Assistant ExpoBeton RDC"
    allow="clipboard-write"
    style="position:fixed; bottom:0; left:0; width:100%; height:100%; border:0; background:transparent; z-index:2147483647;"
></iframe>
✅ Grâce au correctif pointer-events appliqué côté chatbot, l'iframe peut occuper tout l'écran sans bloquer les clics de votre site. Seul le bouton du chat et la fenêtre ouverte sont interactifs.

🧩 Méthode 3 — Injection dynamique via JavaScript

Utile pour WordPress, Google Tag Manager, ou chargement conditionnel :

<script>
(function () {
    var CHATBOT_URL = 'https://web-production-9f398e.up.railway.app/web/chatbot-embed-left.html';
    var iframe = document.createElement('iframe');
    iframe.id = 'expobeton-chatbot';
    iframe.src = CHATBOT_URL;
    iframe.title = 'Assistant ExpoBeton RDC';
    iframe.setAttribute('allow', 'clipboard-write');
    iframe.style.cssText =
        'position:fixed;bottom:0;left:0;width:100%;height:100%;' +
        'border:0;background:transparent;z-index:2147483647;';
    document.body.appendChild(iframe);
})();
</script>

🌐 Intégrations plateformes spécifiques

WordPress

  • Apparence → Widgets → ajouter un bloc HTML personnalisé au pied de page
  • Coller le code de la Méthode 1

Google Tag Manager

  • Créer une balise HTML personnalisé
  • Coller le code de la Méthode 1
  • Déclencheur : Toutes les pages

Shopify / Wix / Webflow

  • Ajouter un bloc Custom Code / Embed HTML dans le pied de page global
  • Coller le code de la Méthode 1

🛠️ Dépannage

  • Le chatbot ne s'affiche pas — vérifier la console (F12), s'assurer que l'URL Railway est accessible
  • Clic sur le site bloqué — vider le cache pour charger la dernière version de chatbot-embed.html
  • Chatbot caché derrière un élément — augmenter le z-index de votre élément ou réduire celui de l'iframe
  • Erreur CORS — l'iframe est autorisé, aucune configuration cross-origin nécessaire côté hôte
