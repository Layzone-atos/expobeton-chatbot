🏗️ Exemple d'intégration du Chatbot ExpoBeton

Voici comment intégrer le chatbot flottant dans votre site web

📋 Instructions d'intégration

✅ Le chatbot flottant apparaît en bas à droite de cette page!
C'est un exemple fonctionnel que vous pouvez tester immédiatement.

Méthode 1: Intégration via iframe (Recommandé)

Copiez simplement ce code HTML avant la balise </body> de votre site:

<!-- ExpoBeton Chatbot -->
<iframe 
    id="expobeton-chatbot-iframe"
    src="https://VOTRE-URL-RAILWAY.railway.app/web/chatbot-embed.html"
    style="position: fixed; bottom: 0; right: 0; width: 100%; height: 100%; border: none; pointer-events: none; z-index: 999999;"
    title="ExpoBeton Assistant"
></iframe>

<script>
    // Permet les interactions avec le chatbot
    document.getElementById('expobeton-chatbot-iframe').style.pointerEvents = 'auto';
</script>
⚠️ Important: Remplacez VOTRE-URL-RAILWAY.railway.app par l'URL de votre déploiement Railway.

Méthode 2: Intégration simplifiée (Une seule ligne)

Version la plus simple - ajoutez juste avant </body>:

<iframe src="https://VOTRE-URL-RAILWAY.railway.app/web/chatbot-embed.html" 
        style="position:fixed;bottom:0;right:0;width:100%;height:100%;border:none;z-index:999999" 
        title="ExpoBeton Assistant"></iframe>

Méthode 3: Intégration avec contrôle JavaScript

Pour un contrôle plus avancé:

<!-- Ajoutez ceci avant </body> -->
<div id="chatbot-container"></div>

<script>
    // Configuration
    const CHATBOT_URL = 'https://VOTRE-URL-RAILWAY.railway.app/web/chatbot-embed.html';
    
    // Créer et injecter l'iframe
    const iframe = document.createElement('iframe');
    iframe.src = CHATBOT_URL;
    iframe.style.cssText = 'position:fixed;bottom:0;right:0;width:100%;height:100%;border:none;z-index:999999';
    iframe.title = 'ExpoBeton Assistant';
    
    // Ajouter au DOM
    document.getElementById('chatbot-container').appendChild(iframe);
</script>

📱 Caractéristiques

  • ✅ Bouton flottant en bas à droite
  • ✅ Responsive (fonctionne sur mobile et desktop)
  • ✅ Collecte des informations utilisateur (nom, téléphone, email)
  • ✅ Support multilingue (Français, English, Swahili)
  • ✅ Intégration facile - aucune modification du CSS de votre site
  • ✅ Ne perturbe pas le contenu de votre site

🎨 Personnalisation

Si vous souhaitez personnaliser la position ou le style:

<!-- Positionner à gauche -->
<iframe src="..." style="position:fixed;bottom:0;left:0;width:100%;height:100%;..."></iframe>

<!-- Réduire la taille sur mobile -->
<style>
    @media (max-width: 768px) {
        #expobeton-chatbot-iframe {
            width: 100% !important;
            height: 100% !important;
        }
    }
</style>

🔗 URL du chatbot après déploiement

Une fois déployé sur Railway, votre URL sera du format:
https://prod-rasa-d3f2c138.up.railway.app/web/chatbot-embed.html

✅ Test

Pour vérifier que tout fonctionne:

  1. Ouvrez votre site web dans un navigateur
  2. Vérifiez que le bouton de chat apparaît en bas à droite
  3. Cliquez dessus pour ouvrir le chatbot
  4. Remplissez le formulaire et testez une question
📌 Note: Le chatbot fonctionne indépendamment de votre site. Il communique directement avec le serveur RASA sur Railway.

🛠️ Dépannage

  • Le chatbot ne s'affiche pas: Vérifiez l'URL dans l'iframe
  • Erreur CORS: Assurez-vous que Railway autorise les iframes
  • Le chatbot ne répond pas: Vérifiez que le service RASA est bien démarré sur Railway
